# Clinical Trial Eligibility UI

Minimal React + Chakra UI prototype for clinical trial protocol and patient matching.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown by Vite.

## What this app includes

- protocol upload placeholder
- patient JSON editor
- simulated eligibility matching summary
- Chakra UI dashboard layout
